## 1. Контекст

`skinlabpro.uz` — сейчас один калькулятор (PDAI, пузырчатка). «Skin Lab Pro» —
**зонтичный бренд** для линейки дерматологических калькуляторов: планируются
витилиго, псориаз, атопический дерматит. Текущий фавикон — плейсхолдер (indigo
квадрат + буква «P»); в хедере — дженерик-иконка калькулятора. Нужен собственный
бренд-знак, не привязанный к одной нозологии.

**Объединяющая идея:** все 4 индекса (PDAI, PASI, VASI, SCORAD/EASI) считают
баллы **по площади/зонам тела** — отсюда концепция знака «зоны тела / mapping».

## 2. Знак (mark) — финал

Вариант **A3 · Crisp Region Stack**. Стилизованная фигура из головы и трёх
зон-полос; зоны — разными оттенками indigo (читается как «шкала балла по зонам»).

**Геометрия** (viewBox `0 0 64 64`):

| Элемент | Параметры |
|---|---|
| Фон | `<rect>` 64×64, `rx=14`, заливка — линейный градиент `slpG` |
| Градиент `slpG` | `x1=0 y1=0 x2=1 y2=1`; stop 0 `#6366f1`, stop 1 `#4338ca` |
| Голова | `<circle>` cx=32 cy=16 r=6, `#ffffff` |
| Зона 1 | `<rect>` x=19 y=26.5 w=26 h=8 rx=4, `#ffffff` |
| Зона 2 | `<rect>` x=15 y=38 w=34 h=8 rx=4, `#c7d2fe` (indigo-200) |
| Зона 3 | `<rect>` x=23 y=49.5 w=18 h=8 rx=4, `#a5b4fc` (indigo-300) |

Знак самодостаточен (фон в составе знака) — работает фавиконом 16px, в хедере и
на любом фоне (светлый хедер сайта, тёмный slate OG-карточки).

**Эталонный SVG (`public/favicon.svg`):**

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
  <defs>
    <linearGradient id="slpG" x1="0" y1="0" x2="1" y2="1">
      <stop offset="0" stop-color="#6366f1"/>
      <stop offset="1" stop-color="#4338ca"/>
    </linearGradient>
  </defs>
  <rect width="64" height="64" rx="14" fill="url(#slpG)"/>
  <circle cx="32" cy="16" r="6" fill="#ffffff"/>
  <rect x="19" y="26.5" width="26" height="8" rx="4" fill="#ffffff"/>
  <rect x="15" y="38" width="34" height="8" rx="4" fill="#c7d2fe"/>
  <rect x="23" y="49.5" width="18" height="8" rx="4" fill="#a5b4fc"/>
</svg>
```

## 3. Файлы и интеграция

| Файл | Действие |
|---|---|
| `pdai-calculator/public/favicon.svg` | заменить плейсхолдер «P» на знак A3 (SVG выше) |
| `pdai-calculator/src/components/Logo.jsx` | создать — React-компонент, inline SVG знака, пропсы `size` (число px, дефолт 40) и `className` |
| `pdai-calculator/src/App.jsx` | в хедере заменить `<CalculatorIcon />` на `<Logo />`; убрать лишний импорт `CalculatorIcon`, если он больше нигде не нужен |

После интеграции хедер: `[знак Skin Lab Pro] PDAI Calculator / подзаголовок` —
бренд-марка + имя продукта.

**`Logo.jsx` — требование к id градиента:** id `slpG` внутри inline-SVG
React-компонента должен быть уникальным, чтобы не конфликтовать с другими
inline-SVG на странице. Header использует один экземпляр `<Logo/>` — фиксированный
id `slpLogoGradient` достаточен. Если в будущем понадобится несколько экземпляров
на одной странице — генерировать id через `useId()`.

## 4. Локап (документированный ассет, вне реализации сейчас)

Полный локап = знак + вордмарк «Skin Lab **Pro**» («Pro» цветом `#6366f1` на
светлом / `#818cf8` на тёмном), **без подписи-таглайна**. Вордмарк — гротеск
(системный sans, weight 800, letter-spacing −0.01em).

Сейчас активно не используется: хедер сайта показывает имя продукта («PDAI
Calculator»), а не бренд-вордмарк. Локап понадобится для будущих бренд-страниц и
соц-превью — фиксируется здесь как референс, в текущую реализацию **не входит**.

optional; можно пропустить.

## 6. Не-цели (YAGNI)

- Растровые версии логотипа (PNG/ICO) — SVG-фавикон покрывает современные
  браузеры; `favicon.svg` уже используется в `index.html`.
- Анимация знака.
- Полная бренд-страница / brand-book.
- Замена имени продукта в хедере на бренд-вордмарк.

## 8. Критерии готовности

- `public/favicon.svg` = знак A3; вкладка браузера показывает новый знак.
- `Logo.jsx` создан; `npm run lint` чист; `npm run build` зелёный.
- Хедер сайта показывает знак вместо дженерик-иконки.
- `npm test` — 26/26 без регрессий (логотип не трогает логику; тесты должны
  остаться зелёными).
- После деплоя: `https://skinlabpro.uz` отдаёт новый фавикон и хедер-знак.
